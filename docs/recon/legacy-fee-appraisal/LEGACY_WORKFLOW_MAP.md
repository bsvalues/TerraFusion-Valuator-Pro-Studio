# Legacy Workflow Map — a la mode TOTAL → TFPS

Real appraiser workflow recovered from config + folder structure + `ReportHistory.XML` (OBSERVED) with the natural sequence INFERRED where noted. Columns: **Step · Legacy screen/function · What the appraiser does · Inputs · Outputs · Current TFPS equivalent · Gap · Recommendation.**

| # | Legacy screen / function | What the appraiser does | Inputs | Outputs | Current TFPS equivalent | Gap | Recommendation |
|---|---|---|---|---|---|---|---|
| 1 | **Order intake** — Mercury / XSites portal (`Mercury/`, `AvailablePlugins.xml`) | Accept assignment from AMC/lender; order metadata flows in | client/lender, address, form type, due date, fee | New `.ZAP` order, order record | "Start New Assignment" → `/assignments` create (title only) | TFPS captures only a title; no client/lender/fee/order metadata, no AMC intake | **Recover** order/assignment fields (P0) → Valuator Pro / WorkfileStore |
| 2 | **Assignment / scope** — WinTOTAL form header | Enter intended use/users, effective/report/inspection dates, property rights, scope, certification, A&LC | USPAP assignment data | Populated assignment section | SubjectContext has fileNumber/address/effectiveDate/intendedUse/propertyRights | Partial — missing intended users, report/inspection dates, scope text, A&LC, appraiser license | **Recover** full assignment model (P0) → Valuator / ReportForge |
| 3 | **Subject property** — 1004 subject page | Enter address, APN, legal, zoning, site, GLA, year built, condition/quality, HBU, tax, flood | property facts | Subject record | SubjectContext (address/city/state/type/gla/yearBuilt/condition/quality + commercial fields) | Partial — no legal/APN-as-evidence, zoning detail, HBU, flood/environmental, tax assessment fields, occupancy/tenancy | **Recover** subject depth (P1) → SubjectContext / Evidence |
| 4 | **Sketch** — DaVinci (`DAVINCI/Forms/Transfer/1004.xfr`) | Draw floor plan; tool computes GLA/areas; transfer to form | drawing | GLA, area breakdown, sketch exhibit | none | **Missing entirely** — no sketch, no area derivation | **Recover (later)** sketch→GLA (P2) → CostForge/Subject + Evidence |
| 5 | **Cost approach** — cost form | RCN, depreciation (phys/func/ext), entrepreneurial incentive, site value | cost inputs | cost indicated value | CostForge Pro (`/api/costforge`) — real engine | Partial — engine exists; lacks entrepreneurial incentive, site-improvement detail, cost-source citation | **Recover** missing cost components (P2) → CostForge |
| 6 | **Sales comparison** — comp grid | Select comps, verify sales, enter per-line adjustments, paired-sales support, comp photos/map | comps + adjustments | adjusted indications, sales value | CompForge (`sales-comparison-panel`, `comp-vault`, regression) | Partial — grid runs in session; **persisted workfile keeps only a comp *summary*, not the full grid/adjustments/comp records**; no comp DB, no sale verification, no comp photos | **Recover** persisted comp grid + comp records (P0) → CompForge/CompVault + Evidence |
| 7 | **Income approach** (as applicable) — 1025/income | Rent roll, market rent, vacancy, expenses, NOI, cap rate, GRM | income inputs | income value | IncomeForge Pro (`income-vault`) — real engine | Partial — engine exists; persisted workfile keeps cap rate/NOI summary only; no rent/expense comps | **Recover** rent/expense comps + persisted detail (P2) → IncomeForge/Evidence |
| 8 | **Reconciliation** — reconciliation page | Weight approaches, applicability, final opinion, narrative | approach values | final opinion of value | Reconciliation panel + `write_high` certify | Good — TFPS reconciliation→certify is solid; legacy lacks an append-only certify trace (**TFPS better here**) | **Keep** TFPS; recover reliability/weighting rationale prompts (P2) |
| 9 | **Review / QC** — ReviewScripts (`Review.fdb`, bias lists) | Run automated checks: missing fields, unsupported adjustments, bias language, completeness, USPAP | report state | warnings/blocks | ReviewForge (`lib/tfps/review.ts`) | Partial — TFPS review has ~8 generic checks; legacy has versioned rule library incl. **bias-language detection** + form-specific completeness | **Recover** deeper rule set + bias check (P1) → ReviewForge/MUSE |
| 10 | **Addenda / narrative** — Custom Addenda (`.tx`), Phrase library, DAVINCI field codes | Insert certifications, A&LC, scope, market narrative via field-code templates + quicklists | boilerplate + field values | narrative pages | MUSE (`write_low` draft) + ReportForge | Partial — MUSE drafts one reconciliation narrative; no addenda library, no certification/A&LC templates, no phrase/quicklist library | **Recover** addenda/cert/A&LC + quicklists (P1) → ReportForge/MUSE |
| 11 | **Report assembly + export** — print engine | Assemble form pages + addenda + exhibits → PDF + MISMO XML | full report | PDF, MISMO XML | ReportForge (HTML export from workfile) | Partial — HTML only; no UAD-form-accurate PDF, no MISMO XML, no exhibits/photo pages/comp-grid pages | **Recover** PDF + MISMO export + exhibits (P1) → ReportForge |
| 12 | **Delivery** — DataCourier / AMC plugins | Send to AMC/lender/UCDP; track status; invoice | report + order | delivered file, status | none | **Missing** — no delivery/UCDP/invoice | **Park** (P3) → later; commercial lane |
| 13 | **Workfile retention** — `.ZAP` + Vault/Titan + `ReportHistory.XML` | Save everything (photos, docs, history) in one bundle; cloud backup | all artifacts | retained workfile | TFPR WorkfileStore (Postgres) + AuditTrace + evidence ledger | Partial — TFPS persists subject/runs/evidence/drafts/certify + append-only audit (**governance better**); but no photos/docs/sketch attachments | **Recover** binary attachments (photos/docs) into Evidence (P1) → TFPR Evidence/Workfile |

**What the software makes easy:** form-accurate data entry, the comp grid, quicklists/phrases, one-bundle workfile, automated QC, one-click PDF+MISMO+deliver.
**What it makes annoying:** Windows-desktop lock-in, opaque binary formats, accreted legacy modules, cloud as bolt-on. (See `DO_NOT_COPY.md`.)
**Old behavior still valuable:** comp grid discipline, sketch→GLA, workfile bundle, QC rules, MISMO/AMC delivery, quicklists.
**Old behavior not to copy:** the WinForms UI, proprietary binary file formats, per-form hardcoding, decades of accreted modules.
